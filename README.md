# Knowledge-Service
Knowledge Service

🔹 1단계: MVP (기본 기능)

회원 관리: 회원가입, 로그인 (JWT or Spring Security)

노트 작성: 글 작성/수정/삭제

카테고리/태그: 노트 분류 기능

검색: 제목/내용 키워드 검색

🔹 2단계: 포트폴리오 강화 기능

마크다운 지원: 코드 블록, 링크, 이미지 첨부

노트 버전 관리: 수정 이력 저장

즐겨찾기: 자주 보는 글 북마크

REST API 문서화: Swagger, ERD 정리

🔹 3단계: 실사용 & 확장

폴더 구조 지원: 계층형 카테고리

태그 기반 추천 글: 관련 노트 연결

통계: 이번 달 작성 글 수, 태그별 글 수 시각화

협업 모드: 공유 링크, 초대 기능 (선택사항)
